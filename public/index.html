SOURCE DE SAUVEGARDE

Ajouter un site

La sauvegarde globale exige les droits root et un accès MySQL complet. Elle exclut /proc, /sys, /dev, /run, /tmp, /mnt, /media, les fichiers MySQL bruts et Docker. Elle aide à reconstruire le serveur; elle n’est pas une image disque démarrable.

Accès MySQL propre à ce site (facultatif)

Privilégiez un fichier de connexion protégé sur le VPS. Sinon, saisissez un compte MySQL ayant accès aux bases choisies.

La copie des fichiers se fait en ligne. Les exports transactionnels MySQL ne garantissent pas à eux seuls la cohérence entre fichiers et bases; les tables non transactionnelles nécessitent une stratégie adaptée.
DÉCOUVERTE DU VPS

Choisir les sites à sauvegarder

Les chemins sont détectés depuis les dossiers CloudPanel et les vhosts NGINX. Vérifiez les bases associées avant l’ajout.

La sélection ne lance pas de sauvegarde immédiate. Vous pourrez vérifier et adapter chaque site après l’ajout.

Vérifier le serveur SSH

Comparez ces empreintes à celles obtenues depuis la console OVHcloud ou un autre canal fiable. La lecture réseau seule ne garantit pas l’identité du serveur.



Restaurer dans un dossier isolé
L’archive sera envoyée vers le serveur de la source, puis extraite dans un nouveau dossier. Les exports SQL seront déposés à côté des fichiers, sans import automatique. Le site actif ne sera pas remplacé.
Le parent doit exister; la destination ne doit pas exister. Python 3.12 ou plus récent requis pour l’extraction sécurisée.
